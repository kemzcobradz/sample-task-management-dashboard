# Sample Task Management Dashboard

A collection of HTML dashboard templates for task management across different organizations.

- **Main_Dashboard.html** — Overview dashboard
- **Dashboard_BioCore_Lab.html** — BioCore Lab
- **Dashboard_Bradford_Criminal_Law.html** — Bradford Criminal Law
- **Dashboard_Gallagher_Partners.html** — Gallagher Partners
- **Dashboard_Hartley_Construction.html** — Hartley Construction
- **Dashboard_Horizon_Projects.html** — Horizon Projects
- **Dashboard_Meridian_Solutions.html** — Meridian Solutions
- **Dashboard_Pinnacle_Vapor.html** — Pinnacle Vapor
- **Dashboard_Sterling_Associates.html** — Sterling Associates
- **Dashboard_Summit_Fleet.html** — Summit Fleet

## Data Files

JSON files (`tasks_v3.json`, `main_stats.json`, `all_active_tasks.json`, etc.) provide the backing data for the dashboards.
